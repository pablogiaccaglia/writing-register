# Current state, not the journey

{#journey.current-state} In documentation, READMEs, reports and meeting cards, say what works and what is true now. Leave out the trial-and-error story, "we found this issue" and "we fixed it", abandoned attempts, paragraphs describing what changed, and the reasoning of whoever wrote the text. When something changes, rewrite the text to describe the new state instead of adding a note about the change.
