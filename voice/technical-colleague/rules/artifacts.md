# Long published pages

- {#artifacts.renders-in-full} A published page is read as it renders before it is shared: every figure appears, every label and title is visible in full, and nothing is cut off or broken.
- {#artifacts.mark-family} On a long page, entries that belong to the same family are marked the same way wherever they appear, so the reader can spot them across the page.
- {#artifacts.sibling-layout} Pages that belong to the same body of work share one layout, carry the sections their kind requires, present procedures, formulas and rationale the same way, and use the same symbol and name for the same quantity; where a symbol the sibling uses is already taken here, the local one is renamed to free it.
