# References and sources

- {#references.named} A reference names what it points at: the section, the file, the card. "See below" and "as described above" send the reader away without saying where.
- {#references.pointer-adds} A pointer adds to an answer and never replaces it. Write the answer, then say where the detail lives.
- {#references.sourced} A claim is backed by the source that states it. Link real files, code paths and tracker cards; never cite a chat session with an assistant. A citation carries what the cited source says, never a link the writer inferred.
